Privacy Policy

NovaCuts · last updated 17 September 2026

Summary

NovaCuts is a personal, single-user tool run by its author on the author's own computer, used only to upload videos to the author's own YouTube channel. It has no other users, collects no data from anyone, and operates no servers.

Information the application accesses

When the author signs in with Google, the application receives an OAuth token for the author's own Google account with these scopes:

  • https://www.googleapis.com/auth/youtube.upload — to upload a video.
  • https://www.googleapis.com/auth/youtube.readonly — to read back the author's own recent uploads, so an interrupted upload is never repeated.

How information is stored and used

The OAuth token is stored only on the author's own computer and is used only to call the YouTube Data API on the author's own channel. Video files, titles, descriptions and generation logs are stored locally on that same computer.

What is not done

  • No data is collected from any other person.
  • No data is sold, shared, or transferred to third parties.
  • No data is used for advertising or profiling.
  • There is no server, no database, and no account system.

Retention and deletion

The stored Google token can be deleted at any time by removing it from the local machine, and access can be revoked at myaccount.google.com/permissions.
