NovaCuts

A personal tool for producing and publishing short videos to my own YouTube channel.

What it does

NovaCuts is a personal, single-user automation project. It writes short animated comedy sketches, renders them locally with ffmpeg, runs quality and content-safety checks, and uploads the finished video to my own YouTube channel using the YouTube Data API.

Who can use it

Only me. It runs on my own computer, against my own Google account. It is not a product, it is not offered to other people, and it has no sign-up.

Google API access

It requests youtube.upload (to upload a video) and youtube.readonly (to confirm an interrupted upload did not already publish, so it never posts the same video twice). It uses no other Google data.
